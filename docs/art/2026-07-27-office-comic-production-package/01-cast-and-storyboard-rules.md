# 01｜人物語氣與漫畫分鏡規則

## 1. 本文件不限制畫風

角色外觀、畫風、線條、上色、比例、光影與實際製作工具全部由美術端決定。
角色設定表只需讓同一角色在後續 64 幅劇情漫畫中保持可辨識與連續，不要求
固定版面或指定色票。

五張角色設定表的 asset ID：

```text
char_male_rover_sheet
char_female_rover_sheet
char_xiangli_yao_sheet
char_changli_sheet
char_boss_mingshi_sheet
```

## 2. 人物在本篇的語氣

### 男漂泊者

- 身分：成年男性新進職員。
- 性格：表面緊張，實際很快被挑起興致。
- 語氣：短句、直白、偶爾吐槽。
- 成人戲：可以被帶著走，也會主動回應，不寫成畏縮或被迫。

### 女漂泊者

- 身分：成年女性新進職員。
- 性格：看似無辜，實際敢先動手。
- 語氣：俏皮、挑釁、喜歡拿工作當雙關。
- 成人戲：常主動把尷尬局面推成情慾場面。

### 相里要

- 身分：成年男性執行秘書。
- 性格：平時整齊克制，失控時反差明顯。
- 語氣：冷靜、精準，成人戲仍習慣用「指導」口吻。
- 成人戲：先確認不是工作命令，再進入情境。

### 長離

- 身分：成年女性執行秘書。
- 性格：成熟、主動、擅長看穿別人在想什麼。
- 語氣：帶笑的命令句、直球挑逗、不做長篇解釋。
- 成人戲：常掌握節奏，但會停下來等對方明確回應。

### 阿列夫一

- 身分：成年男性公司老闆暫代。
- 性格：習慣掌控、把工作與慾望都說得像交易。
- 語氣：簡短、壓迫感強、偶爾出現乾冷笑話。
- 成人戲：每條線都明講「不是命令」，避免把上下級關係畫成強迫。

## 3. 每格分鏡工單欄位

`03` 與 `04` 的每格都提供：

| 欄位 | 用途 |
|---|---|
| 景別／鏡位 | 遠景、中景、近景、俯角、側面等 |
| 姿勢／動作 | 身體方向、手放哪裡、正在做什麼 |
| 表情／視線 | 誰看誰、情緒是否已進入情慾 |
| 服裝／連續性 | 本格解到哪裡，下一格必須接續 |
| 對話 | 角色姓名與氣泡順序 |
| 擬聲／旁白 | 程式疊加的短文字 |
| 留白 | 建議留給文字的低細節區 |

美術可以調整鏡位，只要不改變姿勢、動作、劇情結果和對話閱讀順序。

## 4. R18 漫畫閱讀規則

- 不用一格塞太多動作；每格只表達一個主要動作。
- 臉、手和主要姿勢必須能讀懂。
- 同一路線的服裝狀態逐格改變，不能突然全裸或突然穿好。
- 成人高潮只放在指定格，不提早用完情緒高點。
- 最後一格一定回到辦公室笑點，讓短篇有結尾。
- 權力差配對一定在進入成人動作前用一句對話確認自願。

## 5. 文字與氣泡

- 每格最多三個對話氣泡。
- 氣泡順序依繁中漫畫的上到下、右到左閱讀。
- 對話由程式疊加，美術只需按「留白」欄安排空間。
- 擬聲字同樣由程式處理；美術可畫動態效果，不要畫中文字。
