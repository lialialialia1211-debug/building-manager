# 06｜中間四格動態對話與系統文案

## 1. 用途

第 2～5 格使用玩家放入的卡片，不另畫固定漫畫。提交後，程式把卡面裁成
漫畫分格，依閱讀順序疊加本文件的短句。

每格最多顯示兩句：

- 同格有兩名人物：使用「人物對話」。
- 同格只有一名人物：人物說自己的短句，再接第一張非人物卡的旁白。
- 同格沒有人物：依左到右顯示最多兩張卡的旁白。
- 三卡格仍只顯示兩句，第三張卡以畫面表達，不增加文字。

## 2. 單張人物卡短句

| 卡片 | 短句 |
|---|---|
| 男漂泊者 | 男漂泊者：「我先去。出事再一起跑。」 |
| 女漂泊者 | 女漂泊者：「別把有趣的事都搶走。」 |

## 3. 兩名人物同格

第一句由左卡人物說，第二句由右卡人物回答。

| 左 → 右 | 對話 |
|---|---|
| 男漂泊者 → 女漂泊者 | 男：「今晚別跟我搶。」／女：「看你本事。」 |
| 女漂泊者 → 男漂泊者 | 女：「你跟緊一點。」／男：「妳別突然停。」 |
| 男漂泊者 → 相里要 | 男：「你一直盯著我？」／相：「因為你一直出錯。」 |
| 相里要 → 男漂泊者 | 相：「領帶歪了。」／男：「你可以靠近點整理。」 |
| 男漂泊者 → 長離 | 男：「妳早就有計畫？」／長：「計畫裡本來沒有你。」 |
| 長離 → 男漂泊者 | 長：「跟我來。」／男：「妳至少先說去哪。」 |
| 男漂泊者 → 阿列夫一 | 男：「老闆，你都聽到了？」／阿：「每一句。」 |
| 阿列夫一 → 男漂泊者 | 阿：「留下。」／男：「這算加班嗎？」 |
| 女漂泊者 → 相里要 | 女：「你太正經了。」／相：「妳太不正經。」 |
| 相里要 → 女漂泊者 | 相：「別亂跑。」／女：「那你抓緊。」 |
| 女漂泊者 → 長離 | 女：「前輩要教我嗎？」／長：「看妳學得多快。」 |
| 長離 → 女漂泊者 | 長：「妳在試探我。」／女：「現在才發現？」 |
| 女漂泊者 → 阿列夫一 | 女：「我有條件。」／阿：「坐下來談。」 |
| 阿列夫一 → 女漂泊者 | 阿：「妳膽子很大。」／女：「老闆不喜歡？」 |
| 相里要 → 長離 | 相：「這次我不讓。」／長：「那就來搶。」 |
| 長離 → 相里要 | 長：「你慢了一步。」／相：「還沒結束。」 |
| 相里要 → 阿列夫一 | 相：「你又改行程。」／阿：「只改今晚。」 |
| 阿列夫一 → 相里要 | 阿：「門鎖上。」／相：「你先說原因。」 |
| 長離 → 阿列夫一 | 長：「這次你欠我。」／阿：「妳可以現在討。」 |
| 阿列夫一 → 長離 | 阿：「妳還是來了。」／長：「只為拿走我該拿的。」 |

## 4. 支線反向順序的第六格台詞

以下只替換支線第六格的兩句台詞，美術不變。後續 `01`～`04` 沿用
`04-side-routes.md` 的標準台詞。

| 反向順序 | 第六格替換台詞 |
|---|---|
| 女漂泊者 → 男漂泊者 | 女：「門我鎖了。你還想裝忙？」／男：「我在等妳先開口。」 |
| 相里要 → 男漂泊者 | 相：「你今晚一直盯著我。」／男：「現在才發現？」 |
| 長離 → 男漂泊者 | 長：「老闆辦公室先不管。」／男：「所以妳要先處理我？」 |
| 阿列夫一 → 男漂泊者 | 阿：「留下。我有事要驗。」／男：「這次又要驗什麼？」 |
| 相里要 → 女漂泊者 | 相：「電梯停了，別亂動。」／女：「你抱這麼緊，我怎麼動？」 |
| 長離 → 女漂泊者 | 長：「妳今天惹的麻煩不少。」／女：「所以我來找最會收尾的人。」 |
| 阿列夫一 → 女漂泊者 | 阿：「妳坐了我的位置。」／女：「現在是我的談判桌。」 |
| 長離 → 相里要 | 長：「這份合約歸我。」／相：「妳可以試著拿走。」 |
| 阿列夫一 → 相里要 | 阿：「門鎖上。」／相：「先說今晚不是命令。」 |
| 阿列夫一 → 長離 | 阿：「妳還是來替我收尾。」／長：「別把自己算進工作裡。」 |

## 7. 提交與揭露文案

| 狀態 | 文案 |
|---|---|
| 尚未填滿 | 「還有空格。故事演不下去。」 |
| 可以提交 | 「就照這個順序演下去。」 |
| 揭露開始 | 「門鎖上後，沒人再照規矩來。」 |
| 第六格翻開 | 「最後一格，決定今晚跟誰收尾。」 |

## 8. 無效結局

| 原因 | 第六格文字 |
|---|---|
| 0 名人物 | 「只有辦公室和道具，沒人演。重排。」 |
| 1 名人物 | 「一個人忙完整晚，這不是雙人漫畫。再放一個人。」 |
| 3 名人物 | 「三個人都想插手，四格根本演不完。留下兩個。」 |
| 4～5 名人物 | 「整間公司都擠進來了。這不是尾牙，重排。」 |
| 重複人物／卡片 | 「同一張臉出現兩次。影印機壞了，重排。」 |
| 未知卡片 | 「這張卡不在劇本裡。請重新載入。」 |

按鈕：

```text
回去重排
```

返回後保留八張卡的位置。

## 9. 18 歲確認

標題：

```text
成人內容確認
```

本文：

```text
本遊戲包含成年人之間的露骨性內容。
所有登場人物在本作中均為成年人，互動皆為自願。
```

按鈕：

```text
我已年滿 18 歲，進入遊戲
離開
```
