## 1. 生產目標

這是一款低成本、直球、快速進入成人橋段的全彩 R18 漫畫編排遊戲。
美術不追求高級電影感；優先順序是角色一眼可辨、情境一眼看懂、姿勢清楚、
表情誇張、連續畫面不穿幫。

劇情只保留最低限度的辦公室藉口。支線在第六格建立情境，後續第 1 幅
確認雙方意願並開始脫衣，第 2 幅起進入 R18 主畫面。完美線共 12 幅，
第 4 幅起進入 R18。對白全部由程式疊加，美術內不要畫文字或對話框。

## 2. 不沿用舊案

- 不沿用大樓、房間、管理員、超自然謎團或舊角色。
- 不沿用舊安全版、成人內容開關或舊資產 ID。
- 不沿用任何受保護作品的角色姓名、服裝、髮型或可識別造型。
- 舊檔只留在 Git 歷史，不作為新美術參考。

## 5. 生產批次

完整工單一次開出，以下順序只代表回交優先級：

1. 角色鎖定：5 張角色設定表。
2. 可玩核心：5 張人物卡、4 張場景卡、4 張道具卡，共 13 張。
3. 漫畫外框：固定首格與 5 份 UI。
4. 完美線：1 張第六格與 12 張後續圖。
5. 支線：10 張第六格與 40 張後續圖。

程式端不等待後面批次，缺圖期間使用灰階佔位圖。每批回交後會直接接入
同一套 runtime。

## 6. 美術端只需交付

- 每個遊戲 asset ID 一張無文字、無 UI 的 master PNG。
- 角色設定表同樣交 PNG，不必切圖；設定表可以保留開發註記。
- 道具與指定 UI 使用透明背景 PNG。
- 不必製作 WebP、preview、JSON、manifest 或程式資料。
- 不必把四格漫畫拼成整頁；每一幅分格單獨交檔。

統一交付根目錄：

```text
art/office-comic-2026-07-27/masters/
```

詳細子目錄、尺寸、檔名與 QA 見 `05-export-naming-qa.md`。

## 7. 成人內容共同界線

- 所有角色明確成年，外觀不可幼態化。
- 不使用學生制服、校園道具或含糊年齡描述。
- 每條路線都必須讓雙方保持清醒並主動回應。
- 可以俗辣、挑逗、權力差距明顯，但不可畫強迫、昏迷、藥物控制或恐懼屈從。
- 可以有誇張色情表情與成人姿勢，但不使用暴力、流血、排泄或獵奇傷害。
- 同性與異性配對的完成度一致，不把任何配對做成笑話或懲罰。

## 8. 完成定義

每張圖只有在下列條件同時成立時才算交付：

- asset ID 與檔名完全一致。
- 尺寸、色彩空間與透明背景符合規格。
- 角色臉、髮型、服裝、身高差與體型連續。
- 沒有畫死文字、商標、浮水印或其他作品的角色特徵。
- 重要臉部、手部與道具沒有被裁切。
- 成人畫面的人物、場景、服裝狀態能與前後格接續。
