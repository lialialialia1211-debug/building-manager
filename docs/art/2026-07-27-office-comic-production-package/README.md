## 1. 這份工單負責什麼

這不是畫風 Bible。工單只規定每張圖必須演出什麼：

- 畫面發生的劇情。
- 鏡位、景別與閱讀重點。
- 角色姿勢、肢體動作、表情與視線。
- 服裝狀態及前後格連續性。
- 角色對話、旁白與擬聲字。
- 哪些文字由程式疊加，以及文字需要預留的位置。

美術可自行決定線稿、上色、寫實程度、比例、材質、光影與生成流程。只要
人物、動作、劇情與前後連續性能讀懂即可。

## 3. 漫畫節奏

定位是便宜、直球、簡單易懂的小黃遊：

- 辦公室事件只用一兩句建立理由。
- 不寫長篇背景、陰謀或心理獨白。
- 第六格先給明確曖昧或性暗示。
- 支線第 1 幅直接確認雙方自願並開始脫衣。
- 支線第 2 幅進入 R18，第 3 幅高潮，第 4 幅用低俗笑點收尾。
- 完美線前三幅處理合約、鎖門與同意，第 4 幅起進入 R18。
- 對話以短句為主，每個氣泡原則上不超過 18 個中文字。

## 5. 文字處理

- 美術檔內不要直接畫中文、氣泡、旁白框或擬聲字。
- 文件內標註的所有文字由程式疊加。
- 每格依標示預留一到兩塊低細節區。
- 美術可以畫速度線、汗滴、愛心或震動效果，但不要畫可讀文字。
- 台詞若需要調整長度，由 Codex 在不改變意思的前提下處理。

## 6. 成人內容共同條件

- 所有角色在本作中都是成年人。
- 所有成人互動都保持清醒並有明確主動回應。
- 可以俗辣、挑逗、權力差距明顯，但不使用強迫、昏迷或醉到無法同意。
- 不使用校園、未成年、獵奇傷害、流血或排泄內容。
- 威士忌只作氣氛道具，不作失去意識的手段。

以上是內容邊界，不是畫風限制。

## 7. 交付方式

美術端按 `05-export-naming-qa.md` 完成 PNG 後，直接放到：

```text
content/office-comic/assets/office-comic/{asset_id}.png
```

程式端已完成機器可讀美術計畫、全部台詞資料、六格編排、逐格揭露、結局閱讀器、
缺件占位與尺寸驗證。PNG 檔名和尺寸正確即可直接替換占位，不需要修改程式。
Codex 會在每批回交後重新執行完整驗證，並把精確 commit 部署到 GitHub 預覽後
才交人工 QA。
