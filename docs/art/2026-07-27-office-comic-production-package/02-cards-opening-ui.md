# 02｜卡牌、固定首格與 UI 內容

本文件只指定卡片要畫什麼，不指定畫風、色彩或角色造型。

## 1. 人物卡：5 份

人物卡使用單人全身或接近全身構圖，動作必須在縮圖中一眼能分辨。

| Asset ID | 姿勢／動作 | 表情／視線 |
|---|---|---|
| `card_char_male_rover` | 一手抱合約，一手鬆開加班後的領口或領帶 | 看向辦公室深處，緊張中帶期待 |
| `card_char_female_rover` | 把企劃書抱在胸前，身體微微前傾 | 看向玩家，像剛想到壞主意 |
| `card_char_xiangli_yao` | 站直整理袖口或工作證，另一手拿平板 | 側眼觀察眾人，冷靜克制 |
| `card_char_changli` | 單手抱胸，另一手晃著門卡 | 直視玩家，像已看穿接下來會發生什麼 |
| `card_char_boss_mingshi` | 略側身站在辦公桌或門邊，一手看時間 | 俯視眾人，平靜但有壓迫感 |

人物卡不畫對話；卡名與身分由程式疊加。

## 4. 固定首格：`office_opening_01`

### 劇情目的

用一格交代「簽約前夜、合約鎖在老闆辦公室、五名成年人仍在主管樓層」。
不解釋公司歷史，不介紹超自然設定。

### 鏡位與構圖

- 橫向大格，從公共辦公區看向主管走廊。
- 男漂泊者與女漂泊者在前景翻找合約。
- 相里要與長離分立中景兩側，兩人都看向老闆辦公室。
- 阿列夫一只在遠處電梯口或門邊露出剪影，表示他可能隨時回來。
- 合約夾、辦公室方向與深夜時鐘必須能辨認。

### 姿勢與表情

- 男漂泊者：彎身翻文件，抬頭看向辦公室，明顯焦急。
- 女漂泊者：拿著空資料夾，皺眉但不像害怕。
- 相里要：檢查時間，保持冷靜。
- 長離：手上已有門卡，帶著知道答案的笑。
- 阿列夫一：遠景，不需清楚表情。

### 對話

1. 女漂泊者：「最後一版合約，還鎖在老闆辦公室。」
2. 相里要：「天亮前拿不到，明天大家一起滾。」
3. 長離：「門卡在我手上。要動手，就快一點。」

### 留白

右上、左下與中上各留一塊低細節區，依序放三個氣泡。

## 5. UI 美術：5 份

只指定功能意象，不指定風格：

| Asset ID | 必須傳達的內容 |
|---|---|
| `ui_paper_texture` | 漫畫頁底，不搶人物 |
| `ui_card_back` | 尚未翻開的卡片 |
| `ui_locked_panel` | 第六格完全遮蔽，不出現人物或結局線索 |
| `ui_age_gate_bg` | 深夜辦公室入口，中央可放 18 歲確認 |
| `ui_episode_title` | 可放入《鎖門之後》程式文字的空標題條 |

## 6. 動態文字

人物卡、場景卡與道具卡被放入漫畫格後，程式會依
`06-dynamic-dialogue.md` 疊加短句。美術端不需要為卡片畫氣泡或文字。
