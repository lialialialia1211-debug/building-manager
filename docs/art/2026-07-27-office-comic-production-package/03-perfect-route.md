# 03｜唯一完美路線

## 1. 路線資料

人物配對：江柏宇 × 方曼如。

唯一卡片順序：

```text
江柏宇 → 方曼如
→ 主管樓層走廊
→ 老闆私人辦公室 → 萬用門卡
→ 併購合約 → 百葉窗遙控器 → 威士忌酒具
```

調性：最完整但仍然廉價直球。前三幅只用來關門、簽完合約與確認意願，
第 4 幅開始成人展演，不增加陰謀或長篇心理戲。

共同地點為老闆私人辦公室；深夜冷藍環境光，桌燈和酒櫃使用暖橙光。
江柏宇與方曼如的服裝狀態必須依序變化，不可下一格突然恢復。

## 2. 第六格：1 份

### `ending_perfect_sixth`

- 尺寸：`1638 × 2048`。
- 方曼如用萬用門卡關上老闆辦公室，另一手把江柏宇的領帶拉向自己。
- 江柏宇一手仍拿合約，另一手扶住門板，明確主動靠近。
- 後方百葉窗正在關閉，桌上有兩只尚未飲用的酒杯。
- 畫面性感但尚未進入露骨動作；讓玩家知道命中主要路線。
- 右上保留對話空間。

## 4. 連續性鎖定

- `perfect_01`～`03`：兩人衣著完整，江柏宇領帶逐步變鬆。
- `perfect_04`～`06`：上半身衣物逐步解開，不得突然全裸。
- `perfect_07`～`10`：依實際姿勢保持衣物位置連續。
- `perfect_11`～`12`：逐步穿回，不是一格瞬間復原。
- 合約不可被酒潑濕或撕毀；完美路線必須真的完成工作。
- 威士忌可以倒入杯中，但畫面不得呈現醉倒或意識模糊。
