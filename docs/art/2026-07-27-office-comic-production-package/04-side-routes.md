# 04｜十組人物支線漫畫分鏡

## 1. 共通格式

每組配對有一張第六格與四張後續漫畫：

1. 第六格：事件變成明確性暗示。
2. `01`：雙方清醒確認，接吻並開始脫衣。
3. `02`：直接進入 R18。
4. `03`：主要成人姿勢與高潮。
5. `04`：整理衣服，用辦公室低俗笑點收尾。

角色卡先後只改變程式中誰先說第一句，不要求第二套美術。以下列出的台詞是
標準順序版本，反向版本見 `06-dynamic-dialogue.md`。
