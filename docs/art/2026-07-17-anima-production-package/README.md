## 核准範圍摘要

- 世界：不對應真實國家的低魔架空都市「暮環市」。
- 場景：具有意志的「夜窗大樓」及會移動的第六房間。
- 視覺：清線賽璐璐動畫，深色輪廓、兩階陰影、少量高光。
- 角色：林雨薇 28、陳皓然 31、許安寧 29、周衍 33；全員成年人。
- 遊戲：每房 24 張候選，每局發 12 張、選 6 張、自由排列。
- 結局：普通、主線、親密；兩房合計八支 12 秒影片。
- 成人分流：親密結局有成人版及安全版；其他結局共用。
- 工具：本機 ComfyUI；草稿可用 Anima Turbo，正式圖以 Anima Aesthetic v1.1 為基準。

## 來源層級與相容性

- `content/rooms/*.json` 仍是 panel ID、數值、旗標及必發卡的 source of truth。
- 本包是劇情事件、姿勢、鏡頭及 Anima prompt 的 source of truth。
- 正式整合前需另立實作計畫，把核准後的劇情文字同步回 `content/`。
- 在 runtime 尚未整合正式資源前，`content/asset-manifest.json` 必須維持 `greybox`。
- 安全模式不得載入 `/adult/` 下的圖片、影片、縮圖或 metadata。

## 生產 Gate

先完成 26 項風格鎖定包並取得人工核准，才可量產剩餘主構圖。不得以單張好看取代以下證據：

- 四名角色跨圖一致。
- 六張代表候選卡不看文字仍能辨識行動。
- 十二張同屏、`960×540` 縮圖及 `1280×720` 畫面仍清楚。
- 兩支 3 秒測試影片沒有重大臉部、手部、服裝或背景漂移。
