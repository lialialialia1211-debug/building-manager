# Anima 美術量產與 QA 規格

- 日期：2026-07-17
- 適用範圍：本地 ComfyUI／Anima 靜態圖，以及交由使用者處理的結局影片
- 核心原則：先鎖定風格，再分批量產；每批通過 QA 才能進下一批
- Runtime 狀態：現階段保留灰盒素材，不在本輪直接替換 `content/asset-manifest.json`

## 1. 生產階段與 Gate

### 階段 0：程式灰盒

正式美術進場前，先以現有灰盒確認：

- 每房從 12 張候選卡中選 6 張，且能自由排序。
- 六張卡依玩家排列順序成為實際事件。
- 跨房旗標、結局判定、成人內容開關與安全替代能正確運作。
- 12 張牌池縮圖在 `1280×720` 下仍有足夠操作空間。

灰盒流程未驗收前，不開始 87 張主構圖量產，也不把正式圖寫入 runtime manifest。

### 階段 1：26 項風格鎖定包

| 類別 | 數量 | 必做內容 |
|---|---:|---|
| 角色設定表 | 4 | 林雨薇、陳皓然、許安寧、周衍；每張含正面、3/4、側面、背面與身高比例 |
| 表情胸像 | 8 | 每名角色各做「中性」與「緊張」兩張 |
| 背景 | 2 | Room A 停電客廳、Room B 牆後聲音房間 |
| 無對白代表卡 | 6 | `a1_fuse`、`a2d_chain`、`a4_comfort`、`b1_glass`、`b2n_hall`、`b6_open` |
| 分層來源包 | 2 | `a1_fuse`、`b1_glass`；背景、人物、道具、前景／光效至少四層 |
| 3 秒動態測試 | 2 | 上述兩張各一支，`1920×1080`、24 fps、無音訊 |
| UI 風格板 | 1 | 大樓外觀、漫畫框、按鈕、狀態圖示、字體與縮圖方向 |
| 色彩腳本 | 1 | 大樓、Room A、Room B、親密、謎團五組色盤 |
| **合計** | **26** | 全部通過才可進入階段 2 |

六張代表卡涵蓋調查、邊界、情感、空間開啟與兩個房間的關鍵辨識語彙；風格鎖定階段不製作成人內容。

### 階段 1 驗收條件

- 四名角色的臉型、髮型、服裝、配件與身高差能跨圖穩定重現。
- 邀請 5 名未看文字的測試者辨認六張代表卡；每張至少 4/5 人說出正確主要行動。
- 六張代表卡混入各自的 12 張候選牌池後，在 `1280×720` 畫面仍可快速區分。
- 兩支 3 秒動態測試不得出現臉部漂移、手指變形、衣料跳動、背景溶解或光源忽明忽暗。
- 角色與關鍵道具不依賴對白才能辨識。
- 成人內容關閉時，任何頁面與測試流程都不得請求 `/adult/` 資產。

### 階段 2：完整量產

| 類別 | 數量 | 說明 |
|---|---:|---|
| 角色生產參考 | 64 | 4 設定表＋4 材質表＋32 表情胸像＋24 全／半身姿勢 |
| 環境與道具 | 30 | 8 背景＋6 光效覆蓋＋16 透明道具 |
| UI | 16 | 標誌、地圖、房間、狀態、結局、線索與鎖定圖示 |
| 漫畫主構圖 | 87 | 6 開場＋48 候選＋6 結局 poster／封面＋12 成人回想＋12 安全替代＋3 第六房間 |
| 分層動態來源包 | 20 | 每包至少四層，並保留一張合成主圖 |
| 結局影片 | 8 | 4 支一般／主線＋2 支成人親密＋2 支安全替代；每支 12 秒 |

87 張主構圖沿用原 Web 原型的資產契約；8 支 12 秒影片是本次新增的結局演出，不計入 87 張主構圖。

## 2. 建議量產批次

1. 批次 A：4 名角色設定表、材質表、表情與核心姿勢。
2. 批次 B：Room A 背景、道具與 24 張候選卡。
3. 批次 C：Room B 背景、道具與 24 張候選卡。
4. 批次 D：6 張開場、6 張結局 poster／封面、3 張第六房間。
5. 批次 E：12 張安全替代，先驗證非成人版本的完整可玩性。
6. 批次 F：12 張成人回想，與安全替代逐張對位。
7. 批次 G：8 支結局影片所需的起始幀、結束幀、補間姿勢與分層來源。
8. 批次 H：UI、壓縮、manifest 候選表與整包回歸測試。

每批都要保存生成 metadata、使用的 workflow JSON、模型／LoRA 版本、seed 與人工修圖紀錄。任一批未通過 QA，不啟動下一批。


靜態漫畫格：

```text
{panel_id}_master.webp
{panel_id}_preview.webp
{panel_id}_bg.webp
{panel_id}_character_a.webp
{panel_id}_character_b_or_prop.webp
{panel_id}_fx.webp
{panel_id}_motion.webm
```

影片檔名以 [結局影片規格](05-ending-videos.md) 的八個固定檔名為準。不得使用 `final`、`final2`、`new`、中文空格或無法回溯 panel ID 的檔名。

## 4. 單張靜態圖 QA

每張 `master` 與 `preview` 都要逐項確認：

- [ ] 角色身分、成年外觀、身高比例與角色 Bible 一致。
- [ ] 髮型、服裝、配件、傷痕、持物與左右方向連續。
- [ ] 手指、臉部、關節、衣料與道具沒有明顯生成變形。
- [ ] 線稿、兩階賽璐璐陰影、少量高光符合「清線賽璐璐動畫」。
- [ ] 不含 AI 亂碼、浮水印、對話文字或不明符號。
- [ ] 不看文字也能辨識主要行動與關鍵道具。
- [ ] `960×540` 預覽仍能看清姿勢與敘事焦點。
- [ ] 角色臉、手與關鍵物件都在安全區，UI 不會遮住。
- [ ] 膚色、環境色溫與光源方向符合所屬房間色彩腳本。
- [ ] 成人／安全版本的角色、服裝、場景與時間點能一對一連續。
- [ ] 成人版本只出現成年人，沒有年齡模糊、強迫、醉態或失去意識語意。
- [ ] 檔名、尺寸、色彩空間、Alpha 與壓縮大小符合交付規格。

## 5. 角色一致性 QA

每完成 6 張圖，將同角色裁成同尺寸 contact sheet 比對：

- 臉寬、眼距、髮際線、瀏海缺口與瞳色。
- 肩寬、身高差、成熟體態與 7.5 頭身比例。
- 服裝領口、袖長、鞋型、飾品位置與左右手慣用方向。
- 緊張、戒備、安慰、親密等情緒是否仍像同一個角色。

若同一角色連續 3 張失去辨識度，整批暫停，回到 Character Block、參考圖或 seed 策略修正。

## 6. 12 張牌池／縮圖 QA

每房每次抽出的 12 張候選卡都要以實際 UI 尺寸排版測試：

- [ ] 12 張的主姿勢與剪影至少有足夠差異。
- [ ] 相似場景用不同鏡位、前景物或光色區分。
- [ ] 同批沒有兩張被多數測試者誤認為相同行動。
- [ ] 關鍵卡在 `1280×720` 與 `960×540` 仍可辨識。
- [ ] 卡片即使任意排序，單張因果資訊仍成立，不依賴固定前後文。
- [ ] 成人內容關閉時，縮圖、預載、快取與回想入口皆不洩漏成人圖。

## 7. 成人／安全對位 QA

每一組成人與安全資產採相同事件 ID 對位，逐組檢查：

- 開始時的服裝、光線、房間位置與情緒一致。
- 兩個版本傳達同一段關係進展，只改變親密表現尺度。
- 安全版不以裁切成人畫面代替，必須是完整、自然、獨立可看的構圖。
- 成人版遵守全員成年、清楚同意、無強迫、無醉態、無失去意識、無年齡模糊。
- 成人內容關閉時，網路請求、檔案路徑、預載清單與日誌中均不出現 `/adult/`。

## 8. 12 秒結局影片 QA

依 [結局影片規格](05-ending-videos.md) 驗收每支影片：

- [ ] 總長 `12.0 ± 0.2` 秒；節奏點與四段分鏡一致。
- [ ] 起始幀、關鍵姿勢與結束幀均能對回指定靜態資產。
- [ ] 人臉、手指、衣物、門框、窗框與背景直線沒有漂移或融化。
- [ ] 鏡頭運動只有規格內的推、拉、平移或微手持，不額外旋轉失控。
- [ ] 角色視線、呼吸、髮絲與衣角動作克制，不出現無意義大動作。
- [ ] 一般／主線四支與成人／安全四支使用正確結局旗標與檔名。
- [ ] 成人／安全成對影片的前導與結束情緒連續，但內容尺度清楚分離。
- [ ] 色彩、解析度、幀率、編碼、音訊策略與 runtime 播放需求相符。
- [ ] 影片首幀載入失敗時，對應 poster 仍能完整傳達結局。

## 9. 自動與人工驗證紀錄

每次交付附上：

- 本規格所在的 Git commit SHA。
- ComfyUI workflow JSON 與節點版本。
- checkpoint、VAE、LoRA／LLLite／Control 模型名稱與版本。
- 每張圖的 seed、sampler、scheduler、steps、CFG、尺寸與 prompt 文字。
- 人工修圖工具、修改範圍與輸出日期。
- 六張代表卡的 5 人盲測結果，以及 `1280×720` 牌池截圖。
- 成人內容關閉時的資產請求／預載檢查結果。
- 8 支影片的時長、編碼與逐支人工 QA 結果。

## 10. 停止條件

只要發生以下任一情況，立即停止該批量產：

- 同一角色連續 3 張無法維持臉型、服裝或成年外觀。
- 同一批 12 張中有 2 張以上被多數測試者判斷為相同行動。
- 代表卡在縮圖尺寸下無法辨識，必須依賴卡片文字才能理解。
- 分層素材無法穩定合成，或 3 秒動態測試持續產生漂移。
- 單張 WebP 經合理壓縮後仍超過 900 KB。
- 成人關閉模式仍載入、顯示或記錄成人資產路徑。
- 影片出現角色身分漂移、肢體異常、不同意語意或成人／安全版本混用。
- 工作流、模型版本、seed 或來源 commit 無法回溯。

停止後先修正角色參考、構圖規則、prompt blocks、生成工作流或資產載入策略，再以小樣重新通過 Gate；不得用大量重抽掩蓋系統性問題。
