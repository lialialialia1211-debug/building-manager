# Godot 移植驗收門檻

Godot 實作規劃只能在下列項目全部通過後開始：

- [ ] 兩個房間的自動故事圖驗證為零斷路。
- [ ] 成人內容開啟與關閉時，六個主要結局都可到達。
- [ ] 至少 10 人完成一個房間。
- [ ] 至少 5 人完成兩個房間。
- [ ] 抽樣三選一中，至少 80% 能在沒有對白時正確區分行動意圖。
- [ ] 至少 60% 測試者自願重玩，或明確表示想探索另一結局。
- [ ] 首次完成兩房的中位時間介於 35～55 分鐘。
- [ ] 任一候選結果被評為「與畫面無關」的比例不超過 20%。
- [ ] 26 項風格鎖定包已核准。
- [ ] 兩支 3 秒動態測試沒有重大臉部、手部、服裝或背景漂移。
- [ ] 1280×720 與 1280×800 沒有阻斷操作的重疊。
- [ ] `content/` 的核准 JSON 不含 Web 專屬行為。
