# 內容資料

`office-comic/` 是《鎖門之後》新版程式唯一會公開的內容根目錄：

- `office-comic/office-episode.json`：13 張牌、完美線、20 條有方向支線、
  揭露台詞與 52 格結局台詞。
- `office-comic/office-asset-plan.json`：87 份美術的 asset ID、尺寸與用途。
- `office-comic/assets/office-comic/{asset_id}.png`：美術完成後的直接接入位置。

根目錄其餘舊房間、相簿、角色與資源檔只供版本追溯。Vite 不會把它們複製到新版
正式建置，也不會在執行期載入。
